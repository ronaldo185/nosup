# Objetivo

**Título:** Sistema Inteligente de Segmentación y Análisis del Comportamiento de Clientes mediante Algoritmos de Machine Learning No Supervisado.

## Problema
Una empresa acumula miles de transacciones pero no necesariamente conoce a sus clientes: unos compran a menudo y gastan poco, otros compran poco pero en grandes montos, otros llevan meses sin volver. Sin etiquetas previas, el sistema debe **descubrir** esos comportamientos.

## Objetivo general
Desarrollar un sistema de segmentación de clientes con ML no supervisado sobre datos transaccionales para identificar patrones de consumo, comparar algoritmos de agrupamiento y generar perfiles comerciales interpretables.

## Objetivos específicos
1. Validar y limpiar el dataset UCI Online Retail con trazabilidad de cada paso.
2. Construir variables RFM y comerciales por cliente.
3. Comparar K-Means, Jerárquico (Ward), GMM, DBSCAN y HDBSCAN con métricas internas y de estabilidad.
4. Convertir los clusters en perfiles de negocio con acciones recomendadas.
5. Presentar resultados en un dashboard interactivo con bitácora y reportes PDF.
